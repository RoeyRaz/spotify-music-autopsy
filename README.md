# ⚡ SPOTIFY MUSIC AUTOPSY

> A brutal breakdown of the tracks you desperately try to hide.

**Spotify Music Autopsy** is an interactive, highly-stylized data analytics web application built with **Streamlit** and **Spotipy**. It pulls your top artists and tracks, subjects you to a fake psychological interrogation, and generates an unhinged "forensic audit" of your music taste complete with dynamic charts, judgment tags, and exportable autopsy reports.

---

## ✨ Key Features

- **Glassmorphism UI**: Modern, dark-mode dashboard with smooth animations and custom CSS styling.
- **Secure Authentication**: Uses Spotify OAuth (`spotipy`) to securely fetch your personal short-term top artists and tracks.
- **Psychological Questionnaire**: Interactive multi-stage interrogation that logs your "denial" into the final report.
- **Real Rotation Metrics**: Displays your actual rotation rank and Spotify popularity scores with sleek Streamlit bar charts.
- **Exportable Reports**: Generate and download a comprehensive text summary of your musical autopsy.

---

## 🛠️ Tech Stack

- **Python**
- **Streamlit** (UI & Dashboard)
- **Spotipy** (Spotify Web API Wrapper)
- **Pandas** (Data handling & visualization)
- **Python-Dotenv** (Environment variable management)
